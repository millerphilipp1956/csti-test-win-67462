## About CSTI Game Personality Test

CSTI Game Personality Test is a browser-based personality quiz centered on CS2 and CSGO player identity. It uses a 35-question flow to build a game personality profile, estimate rank tendencies, and map results to one of 15 personality types.

The experience is designed for quick interactions on the web, with responsive layout support and multilingual content so it can work comfortably across devices and audiences. It combines simple test flow, visual feedback, and audio or animation effects to make the result page feel more engaging than a static questionnaire.
